# Smart Streetlight System Using Arduino

## Project Overview
This project is an Arduino-based Smart Streetlight System that automatically controls streetlights based on the surrounding light intensity using an LDR (Light Dependent Resistor) sensor.

The main objective is to reduce unnecessary electricity consumption by automatically switching streetlights ON and OFF.

## Working Principle
The LDR sensor detects the intensity of surrounding light and sends the corresponding signal to the Arduino UNO.

- **During daytime:** When sufficient light is detected, the streetlight remains OFF.
- **During nighttime:** When the surrounding light decreases, the streetlight automatically turns ON.

## Components Required
- Arduino UNO
- LDR Sensor
- LED
- 220Ω Resistor
- 10kΩ Resistor
- Breadboard
- Jumper Wires

## Tools Use
-Tinkercad

## Applications
- Automatic street lighting
- Energy-saving lighting systems
- Smart city applications

## Conclusion
This project demonstrates a simple and cost-effective automatic streetlight system using Arduino and an LDR sensor. It helps reduce manual operation and unnecessary power consumption.
